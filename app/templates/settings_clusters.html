How to register a new Kubernetes cluster? ▼

Method A — Bearer token (api_url + token)

Create a service account token on the target cluster:

kubectl -n kube-system create serviceaccount k8s-ui-sa
kubectl create clusterrolebinding k8s-ui-binding \
  --clusterrole=cluster-admin --serviceaccount=kube-system:k8s-ui-sa
kubectl -n kube-system create token k8s-ui-sa --duration=87600h

Then in this UI:

  1. Click "+ Add Profile" below
  2. Fill in Profile Name + API URL, then click Save Profile
  3. Click "Login & Switch" on the new profile row
  4. Paste the bearer token, then click "Login & Switch" again

Method B — Import kubeconfig file

  1. Click "Import Kubeconfig" at the bottom of this page
  2. Paste a kubeconfig YAML (or upload a file)
  3. A profile is auto-created from the kubeconfig's current-context

After import, click "Login & Switch" on the new row to activate it.

Import Kubeconfig ▼

Use this to connect to a vanilla Kubernetes cluster by pasting its kubeconfig file. The kubeconfig will be merged into ~/.kube/config (a backup of any existing file is made first as ~/.kube/config.bak), and a new cluster profile will be created automatically from the current-context.
